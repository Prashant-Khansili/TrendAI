ℹ️ Overview

TrendAI is a smart trend intelligence system designed for social media agencies and small businesses.  
It helps users quickly identify trending topics, understand their context, and convert them into content-ready insights.

This project was built to explore:
- Data pipelines
- API integration (Google Trends + web search)
- Backend design using Django
- Structured data generation for AI-driven applications

⬇️ Installation

Clone the repository:

git clone https://github.com/Prashant-Khansili/TrendIAI.git
cd TrendIAI

Create virtual environment:

python -m venv venv
venv\Scripts\activate   # Windows
source venv/bin/activate  # Mac/Linux

Install dependencies:

pip install -r requirements.txt

Run the project:

python manage.py runserver
